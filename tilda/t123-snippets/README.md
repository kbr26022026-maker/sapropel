# T123 Snippets

В этой папке лежат готовые сниппеты для блоков Tilda `T123`.

Как использовать:

1. Откройте нужный файл из этой папки.
2. Скопируйте его целиком.
3. Вставьте в блок `T123`.
4. Опубликуйте и проверьте страницу.

Важно:

- Перед вставкой блоков на сайте уже должны быть подключены `_global/head.html` и `_global/global.head.html` из основной папки `tilda`.
- Файлы `07-resources.t123.html`, `09-contact.t123.html` и `10-footer.t123.html` содержат плейсхолдеры вида `__TILDA_*__`.
- Эти плейсхолдеры нужно заменить на реальные URL файлов, загруженных в Tilda/CDN.
