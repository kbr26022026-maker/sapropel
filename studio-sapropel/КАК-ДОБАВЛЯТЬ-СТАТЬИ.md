# Как добавлять и редактировать статьи

Статьи блога сайта ecoorganica54.ru теперь редактируются в визуальной панели
(CMS) — без программиста и без правок кода.

## Где находится панель

Адрес: **https://sapropel-ecoorganica.sanity.studio/**

Войдите тем аккаунтом (Google), на который вас пригласили. После публикации
изменения появляются на сайте автоматически в течение нескольких секунд —
пересобирать сайт не нужно.

> **Если интерфейс открылся на английском:** нажмите на свой аватар справа
> сверху → пункт языка → выберите **«Русский»**. Выбор запомнится.

## Как добавить новую статью

1. Откройте панель: слева раздел **«Контент» → «Статьи»**.
2. Нажмите кнопку **«+»** (Создать) сверху.
3. Заполните поля:
   - **Заголовок** — название статьи.
   - **Адрес страницы (slug)** — нажмите **«Generate»**, адрес создастся
     автоматически из заголовка (кириллица превращается в латиницу). Менять
     не обязательно.
   - **Категория** — Агрономия / Наука / Практика / Новости.
   - **Дата публикации** — по умолчанию текущая.
   - **Обложка** — перетащите картинку или нажмите для загрузки с компьютера.
   - **Краткое описание** — 1–2 предложения для карточки в списке статей.
   - **Автор** — по умолчанию «Редакция «Эко Органика»».
   - **Вводный абзац (лид)** — выделенный вступительный текст.
   - **Текст статьи** — основной текст. Панель форматирования сверху:
     заголовки (Заголовок 2 / 3), списки, цитата, **жирный**, *курсив*,
     ссылки и вставка картинок прямо в текст.
   - **Похожие статьи** — до 3 статей в блок «Читайте также». Если оставить
     пустым, сайт сам подставит свежие статьи.
4. Нажмите **«Опубликовать»** (зелёная кнопка справа внизу). Готово.

## Как отредактировать существующую статью

1. Откройте **«Контент» → «Статьи»** слева, выберите нужную.
2. Внесите правки.
3. Нажмите **«Опубликовать»**. Изменения уйдут на сайт автоматически.

## Полезно знать

- Пока статья не опубликована (**«Опубликовать»**), на сайте её не будет —
  черновик виден только в панели.
- Картинки загружаются прямо в CMS, отдельный хостинг не нужен.
- Время чтения и подпись категории на карточке считаются автоматически —
  отдельно заполнять не нужно.
- Удалённая статья пропадает с сайта; ссылки на неё начнут показывать
  «Статья не найдена».
